# Gangnam Beauty Guide · Review Lens

This is a self-contained interface prototype for a review-syndication feature. It demonstrates a trust-first way to help English-speaking medical-tourism buyers compare Korean clinic reviews:

- Korean source phrase beside an English translation
- normalised procedure, recovery, price, and source fields
- visible confidence and verification signals
- search and filters for a practical shortlist workflow
- uncertainty notes that keep personal experience separate from medical advice

The six records are fictional sample data. They are intentionally labelled in the UI and must not be treated as clinic recommendations or medical information. The prototype has no backend and can be opened directly from `index.html`.
